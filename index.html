Каталог предметов Кузни

Как пользоваться:
1. Редактируй предметы — черновик сохраняется в браузере автоматически.
2. Когда готово — нажми Экспорт JSON и замени файл data.json в репозитории.
3. Игроки увидят обновлённую версию после коммита.
4. Сбросить черновик — вернуться к данным из data.json.
